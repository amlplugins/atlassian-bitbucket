# @amlplugins/atlassian-bitbucket

Native `bitbucket` SDK re-exported under the `@amlplugins` namespace.

> Bitbucket Cloud REST API 2.0 — repositories, pull requests, pipelines, issues, deployments.

## Install

```bash
npm install @amlplugins/atlassian-bitbucket
```

## Use

```ts
import { /* named exports from bitbucket */ } from "@amlplugins/atlassian-bitbucket";
// or
import sdk from "@amlplugins/atlassian-bitbucket";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
